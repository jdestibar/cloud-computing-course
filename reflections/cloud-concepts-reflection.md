# Cloud Computing Reflection

Cloud computing has become an important part of my daily life because many of the applications I use depend on cloud services. Three of the services I use regularly are Google Drive, Canva, and Facebook Messenger. Google Drive allows me to store, access, and share my files from any device with an internet connection. Canva helps me create presentations, posters, and other graphic designs online, while Facebook Messenger allows me to communicate instantly with my classmates, friends, and family.

These services are examples of Software as a Service (SaaS) because they provide complete software applications that users can access through a web browser or mobile app without installing or managing the underlying infrastructure. They are also classified under the Public Cloud deployment model because they are available to anyone over the internet and are managed by their respective service providers. As a user, I only need an internet connection and an account to access their features.

Version control is an essential part of cloud computing projects because it keeps track of every change made to files, configurations, and source code. It allows developers to review previous versions, restore files when mistakes happen, and work together without overwriting each other's work. This is especially useful in cloud environments where multiple team members may be working on the same project simultaneously.

Git and GitHub make collaboration easier by providing a centralized platform where team members can store, manage, and update project files. Features such as commits, branches, pull requests, and version history help organize development and reduce errors. They also make it easier to identify who made specific changes and when those changes were made. Overall, cloud computing and version control work together to improve productivity, collaboration, and reliability, making them valuable tools for both students and professionals working on technology-related projects.
